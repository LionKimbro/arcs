## Existing application
Created: 2026-10-11
Modified: 2026-10-11

Today already exists and is useful for tracking things about a day. Each day has a page. Each page can contain multiple tabs, which Lion can create and delete. Tabs are divided into rows with one, two, or three columns. The layout can be rearranged, and panels can contain whiteboards, markups, images, and other material.

Previous-day and next-day controls navigate between days. The **Now** button returns to the present day.

## Relationship to other cockpits
Created: 2026-10-11
Modified: 2026-10-11

Today provides daily orientation. [Focus](focus.md) overlaps with it while concentrating on attention management. [Projects](projects.md) is planned to adopt Today's layout system for context spanning multiple days. The earlier Arcs notes use the name “Temple of Focus”; that historical wording does not establish that Today, Focus, and Arcs are the same application.

Arcs' browsing use case includes sending an instruction to Today to navigate its presentation to a specific day within an arc, most likely the day of an associated event. [FileTalk](filetalk.md) is the chosen cross-application communication mechanism. The command schema and endpoint details remain to be specified.
