Modified: 2026-10-11

## Browsing
Created: 2026-10-11
Modified: 2026-10-11

Browse an arc to see its parents, read associated journal entries, inspect events, and examine connected projects, files, graphics, and other contextual resources. An arc can make important images available, such as a team photo or a picture of a place significant during that passage. These associations enrich the record of the arc; their exact schemas and presentation remain open.

“Travel to a day” means sending an instruction to the Today application to move its presentation to a specific day within the arc, most likely the day of an event. It is cross-application navigation, not merely selecting a date inside Arcs. [FileTalk](filetalk.md) is the chosen communication mechanism. The command schema and handling of uncertain event dates remain to be designed.

## Logging a journal entry
Created: 2026-10-11
Modified: 2026-10-11

Locate a current arc and enter a journal entry about it. This establishes an authoring use case alongside browsing existing entries. Journal entries are usually associated with one arc but may be associated with several; this initial workflow starts from a current arc.

## Logging an event
Created: 2026-10-11
Modified: 2026-10-11

Record an event associated with an arc. Logging an event does not inherently end or transform the arc: many events occur while its defining character continues. The event describes what happened and has temporal information, whose uncertainty can be represented through ChronoMark.

## Logging an event plus a transition
Created: 2026-10-11
Modified: 2026-10-11

Record an event that marks the end of one arc and the beginning of a new arc. This is an explicit transition use case, distinct from ordinary event logging. The same event provides the connection between the ending and beginning passages. Exact authoring steps, relationship types, boundary representation, and save behavior remain to be designed.
