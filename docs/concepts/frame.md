## Meaning
Created: 2026-10-11
Modified: 2026-10-11

A frame is a predefined view specifying what to show, what not to show, and how to show it visually. Lion introduced this concept while considering the Life Chapters interface proposal. It provides a way to describe choices of presentation and inclusion; its precise representation and capabilities remain to be designed.

## Open design questions
Created: 2026-10-11
Modified: 2026-10-11

Whether frames are user-editable, saved M1-mappable objects, or fixed application views has not been settled. How a frame relates to bands, selected arcs, time ranges, and alternative visual arrangements is also open. Do not assume that the same data must appear in every frame or that a frame is an arc, a containing arc, or a window.
