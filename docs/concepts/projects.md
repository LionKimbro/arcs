## Project cockpit
Created: 2026-10-11
Modified: 2026-10-11

Projects usually span multiple days. A project cockpit supports project tracking and provides relevant context. The current system has panels. Lion plans to make it use the same tab, row, and column system as [Today](today.md); this is a planned change, not a claim that the change is already implemented.

## Relationship to arcs
Created: 2026-10-11
Modified: 2026-10-11

Projects and [arcs](arc.md) can both span days, but a project and an arc have not been defined as equivalent. How project objects connect to arc objects remains open.
