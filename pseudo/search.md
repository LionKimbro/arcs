# Basic Search

Basic owns classification tags. Disk migrates and persists; Mem searches accepted
objects. Core owns independent input/executed/results/selection state and query
generations. Old or closed-view returns are ignored. Domain returns refresh
executed queries, preserving surviving selections and edited input.

Core session names bind individual UUIDs, shadow Basic names, and expire at exit.
Assignment and rebinding are atomic. Tk owns clipboard I/O. Copy references as a
UUID array; copy criteria as a versioned search. Recognition only offers; reset
or explicit conflict resolution adopts. Search remains a separate action.

Tk presents amber search windows and read-only object inspection. Temporal
predicates and Welder actions wait for their own design.
